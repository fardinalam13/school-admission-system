# School Admission System

Take-home assignment: an online school admission system where seats in each class shift are
limited and are granted first-come, first-served through time-limited holds.

- `backend/`  – ASP.NET Core 8 Web API + PostgreSQL
- `frontend/` – React 18 (JavaScript, Vite)
- `docker-compose.yml` – starts PostgreSQL, backend and frontend together
